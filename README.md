# Barber Landing Page

Premium single-page barbershop website built with Create React App, TypeScript,
Tailwind CSS, and Framer Motion.

## Sections

- Hero with booking CTA
- Story and shop positioning
- Services and pricing
- Reviews and trust signals
- Gallery
- Barber team
- Contact, hours, and map
- Footer with social links

## Commands

```bash
npm start
npm run build
npm test -- --watchAll=false
npx eslint src/
npx prettier --write src/
```

## Notes

The project uses Tailwind CSS v3 through CRA's webpack pipeline. Fonts are loaded
in `src/index.css`, and brand tokens are configured in `tailwind.config.js`.
